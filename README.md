# Soul Balance — Meal & Workout Tracker

A single-file, mobile-friendly calorie, macro, and workout tracker. Open `soul-balance-tracker.html` directly in a browser, or host it (e.g. GitHub Pages, Netlify Drop) to use it from your phone.

## Features
- Daily calorie & macro tracking with go-to meals (ingredients + amounts + macros)
- Workout logging, including strength sets with weight/reps/sets and progression trends
- Weight goal tracking with a progress trajectory chart
- Weekly meal planner with auto-scaled portions and a grocery list grouped by store
- Data export/import (JSON backup) — all data is stored locally in the browser

## Usage
Just open `soul-balance-tracker.html` in any modern browser. No build step, no dependencies, no server required.
